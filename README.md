# Læringsti: Hvorfor svinger bestandene i den boreale skogen?

Interaktiv læringssti om hva som driver bestandssvingninger hos smågnagere og skogsfugl i den boreale skogen.

Læringsstien omhandler blant annet predasjon, den alternative byttedyrhypotesen (APH), blåbær og plantekvalitet, klima, tidsforsinkelser og synkrone bestandssvingninger.

Materialet er utviklet for undervisning ved NMBU.
